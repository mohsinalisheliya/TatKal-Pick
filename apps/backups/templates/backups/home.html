How the automatic part runs

While the system is running, it checks every minute whether a backup is due. If the computer was off at the scheduled time, the backup runs as soon as the system starts again.

If you want backups even when the website is not open, add a Windows scheduled task once (run this in Command Prompt). It does nothing unless a backup is due:

{{ task_cmd }}

Tip: a pendrive can be lost. Turn on BitLocker To Go for it (right-click the drive in Explorer) so the backup cannot be read by someone else.
